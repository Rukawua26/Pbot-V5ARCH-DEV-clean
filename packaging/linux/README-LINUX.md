# SniperBot Linux Portable

## Opcion con Python instalado

1. Instala Python 3.12.
2. Extrae el proyecto.
3. Ejecuta:

```bash
bash packaging/linux/start_bot.sh
```

## Opcion Release Portable

1. Descarga `SniperBot-Linux-Portable.tar.gz` desde GitHub Releases.
2. Extrae y ejecuta:

```bash
tar -xzf SniperBot-Linux-Portable.tar.gz
cd SniperBot
./SniperBot
```

El primer arranque crea `~/.config/SniperBot/.env` y siempre inicia en PAPER.
