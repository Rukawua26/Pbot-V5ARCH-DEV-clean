# Features

Create one folder per feature:

```txt
spec/features/001-feature-name/
  spec.md
  plan.md
  tasks.md
  verify.md
```

For runtime-critical work, include explicit safety criteria in `spec.md` and verification commands in `plan.md`.

Always check `docs/engineering/memoria-tecnica.md` and, for pending improvements, `docs/roadmap/mejoras-pendientes.md`.
